# Dietary Requirements Translator

A React application that helps users translate their dietary requirements into different languages. This is particularly useful for travelers or people who need to communicate their dietary needs in foreign countries.

## Features

- Automatic language detection based on browser settings
- Selection of base language
- Comprehensive dietary requirements selection:
  - Dietary preferences (vegan, vegetarian, etc.)
  - Food intolerances
  - Food allergies
- Translation of requirements into multiple languages
- Modern, user-friendly interface

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm (v6 or higher)

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd dietary-translator
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The application will open in your default browser at `http://localhost:3000`.

## Usage

1. The application will automatically detect your browser's language and set it as the default.
2. You can change the base language if needed.
3. Select your dietary requirements:
   - Check any dietary preferences that apply
   - Indicate any food intolerances
   - List any food allergies
4. Choose the target language for translation
5. View your dietary requirements translated into the selected language
